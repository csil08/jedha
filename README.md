# Data science projects

## Introduction

My name is Catherine and I am currently following a [data scientist training at Jedha](https://www.jedha.co/formations/formation-data-scientist).

This repository showcases the data science projects completed during my training, as part of the requirements for obtaining the [CDSD certification](https://www.francecompetences.fr/recherche/rncp/35288/).

The repository is structured around the certification competency blocks, each containing one or more data science projects.
